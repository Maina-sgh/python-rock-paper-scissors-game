# 🎮 Rock Paper Scissors Game

## 📌 Project Description

Rock Paper Scissors is a simple and interactive command-line game developed using Python. In this game, the player competes against the computer by choosing one of three options: Rock, Paper, or Scissors.

The computer randomly selects its choice, and the winner is decided based on the traditional rules of the game.

This project is designed for beginners to understand Python programming concepts such as conditional statements, loops, random module, user input, and basic logical operations.

## 🎯 Objective

The main objective of this project is to develop a fun and interactive game while improving programming and problem-solving skills using Python.

## 🕹️ Game Rules

The game follows three simple rules:

1. Rock beats Scissors.
2. Scissors beats Paper.
3. Paper beats Rock.

If both the player and computer choose the same option, the result is a draw.
